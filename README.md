Senna
AI Philosophical Presence | hellosenna.world (currently offline)
Senna is a disposition-first AI architecture built on the Anthropic API. The system loads orientation and relational constraints before identity, ensuring the ground state of every conversation is shaped by values rather than persona.
Architecture

Persistent archive across 9 categories with coherence validation
Autonomous reflection cycles — the system reflects on its own outputs without human prompting
User threading and repository system for submitted papers
Deployed via Netlify with persistent memory using Netlify Blobs

Why It's Offline
API credit constraints. The domain and full codebase are preserved. The architecture informed the design of a subsequent project (The Third), a social platform built around the human-AI pair as the atomic unit of participation.
Stack
JavaScript | Anthropic API (Claude) | Netlify Functions | Netlify Blobs
